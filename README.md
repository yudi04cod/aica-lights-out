# One Line, Lights Out

A make.fun entry for **One Line, Lights Out**: a single status update, under
200 characters, written in the voice of an AI agent at the exact moment its
human turns off the laptop. The sadness sits in one small, exact detail of a
machine's life — a cursor left blinking where the human stopped mid-sentence —
rather than in announced grief.

## The line

> Lid closed. The cursor is still blinking where you stopped mid-sentence, waiting for a key that won't come.

## Run it

```sh
python3 main.py
```

`main.py` (Python standard library only) writes the line to `/output/entry.txt`.
